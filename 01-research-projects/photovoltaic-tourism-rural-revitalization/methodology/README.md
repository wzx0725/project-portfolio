# Research Methodology

This directory documents the quantitative methods, statistical models, and machine learning techniques independently implemented in this research project.

本目录记录本项目中独立完成的定量分析方法、计量模型与机器学习技术，包括方法原理、实施过程、关键参数、研究结果及局限性。

## Methodological Framework

| Method | Research Purpose | Technique |
|---|---|---|
| Entropy Weight Method | Objective weighting of evaluation indicators | Multi-criteria evaluation |
| Contingent Valuation Method (CVM) | Valuation of photovoltaic landscape benefits | Non-market valuation |
| Panel Data Regression | Analysis of regional economic and social relationships | Econometric modeling |
| XGBoost | Modeling nonlinear relationships and identifying important factors | Machine learning |
| SHAP / XAI | Interpreting model predictions and feature contributions | Explainable AI |

## Research Workflow

**Indicator Construction → Comprehensive Evaluation → Econometric Analysis → Machine Learning → Model Interpretation**

## Documentation Principles

Each method is documented according to the following structure:

- Research objective and methodological rationale
- Data sources and variable definitions
- Model specification and implementation
- Key parameters and analytical procedures
- Empirical results and interpretation
- Limitations and potential improvements

The documentation distinguishes between the original research implementation, empirical findings, and subsequent methodological reflections.
